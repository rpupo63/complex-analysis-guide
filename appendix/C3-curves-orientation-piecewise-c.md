title: Curves, orientation, piecewise $C^1$ boundaries
status:

- cited
---
<ul>
<li>A <em>closed curve</em> is a continuous map $\gamma:[a,b]\to\R^2$ with $\gamma(a)=\gamma(b)$; it is <em>simple</em> if it does not cross itself (injective on $[a,b)$). A circle is simple; a figure eight is not.</li>
<li><em>Jordan curve theorem</em> (cited): a simple closed curve splits the plane into a bounded inside $D$ and an unbounded outside, with the curve as their common boundary.</li>
<li>The curve is <em>positively oriented</em> if $D$ lies on the left as you travel along it: anticlockwise for a circle. Then the outward normal $n$ is the unit tangent $t$ turned clockwise by $90°$: if $t=(t_1,t_2)$, $n=(t_2,-t_1)$.</li>
<li>A boundary is <em>piecewise $C^1$</em> (or piecewise smooth) if it consists of finitely many curves, each continuously differentiable with nonzero velocity, joined at finitely many corners. Polygons, disks and unions of grid squares qualify. This is what the divergence theorem ([A.6](apx:A6)) needs.</li>
</ul>

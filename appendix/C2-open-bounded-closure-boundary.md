title: Open, bounded, closure, boundary
status:
- defined
---
<p>Let $\Omega\subset\R^2$ and write $D_r(P)$ for the open disc of radius $r$ about $P$.</p>
<ul>
<li>$\Omega$ is <em>open</em> if every $P\in\Omega$ has some $D_r(P)\subset\Omega$.</li>
<li>$\Omega$ is <em>bounded</em> if it lies in some disc $D_R(0)$.</li>
<li>$P$ is a <em>boundary point</em> of $\Omega$ if every disc $D_r(P)$ meets both $\Omega$ and its complement. The set of boundary points is $\class{ntn-dOm}{\partial\Omega}$.</li>
<li>The <em>closure</em> is $\overline\Omega=\Omega\cup\class{ntn-dOm}{\partial\Omega}$.</li>
</ul>
<p>For an open $\Omega$, $\class{ntn-dOm}{\partial\Omega}$ is disjoint from $\Omega$. A bounded closed set such as $\overline\Omega$ is compact, so continuous functions on it attain a maximum and a minimum (the extreme value theorem, cited).</p>

<div class="env"><span class="hd">Theorem.</span> Every continuous function on a closed interval $[a,b]$ is a uniform limit of polynomials.</div>
<p>Applied to $|x|$ on $[-1,1]$: smooth functions (polynomials) can converge uniformly to a function with a corner. @rem:uniform-limits-are-usually-not-smooth gives an explicit smooth sequence with the same behaviour.</p>

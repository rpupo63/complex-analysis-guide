<div class="env"><span class="hd">Theorem (cited).</span> A continuous real function on $[a,b]$ takes every value between $f(a)$ and $f(b)$.</div>
<p>Consequence used in @thm:rouche: a continuous function $[0,1]\to\R$ that takes only integer values is constant. If $N(0)\ne N(1)$, it would take the non-integer value halfway between them. In the language of [C.4](apx:C4): $[0,1]$ is connected.</p>

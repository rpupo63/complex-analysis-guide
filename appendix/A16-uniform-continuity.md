<p>$g$ is <em>uniformly continuous</em> on a set $T$ if for every tolerance $\epsilon\gt0$ there is one $\delta\gt0$ that works everywhere: $|g(q)-g(q')|\lt\epsilon$ whenever $q,q'\in T$ and $|q-q'|\le\delta$. Plain continuity allows $\delta$ to depend on the point.</p>
<div class="env"><span class="hd">Theorem (Heine–Cantor, cited).</span> A continuous function on a compact set is uniformly continuous.</div>
<p>Without compactness this fails: $g(x)=1/x$ is continuous on $(0,1]$ but needs ever smaller $\delta$ near $0$. @lem:uniformly-a-17-on uses the theorem on the compact set $\class{ntn-dOm}{\partial\Omega}$.</p>

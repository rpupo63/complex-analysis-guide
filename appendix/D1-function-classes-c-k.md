title: 'Function classes: $C^k$, smooth'
status:
- defined
---
<ul>
<li>$C(\overline\Omega)$: continuous on $\overline\Omega$, boundary included.</li>
<li>$C^k(\Omega)$: all partial derivatives up to order $k$ exist and are continuous in $\Omega$. "$h$ is $C^2$" means $C^2(\Omega)$.</li>
<li><em>Smooth</em> ($C^\infty$): $C^k$ for every $k$.</li>
<li>$C^2(\Omega)\cap C(\overline\Omega)$: twice continuously differentiable inside, continuous up to the boundary. This is the natural class for the classical Dirichlet problem (@def:dirichlet-problem): enough derivatives inside to state $\class{ntn-Delta}{\Delta} h=0$, enough continuity at the edge to state $h=g$.</li>
</ul>

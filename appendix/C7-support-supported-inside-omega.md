title: Support; "supported inside $\Omega$"

- defined
---
<p>The <em>support</em> of a function $f$ is the closure of the set where $f\ne0$. The hat $\class{ntn-phi}{\varphi_{ij}}$ has support $[x_{i-1},x_{i+1}]\times[y_{j-1},y_{j+1}]$.</p>
<p>A function is <em>supported inside $\Omega$</em> (or <em>compactly supported in $\Omega$</em>) if its support is a closed bounded set contained in $\Omega$. Such a function vanishes on a whole neighbourhood of $\class{ntn-dOm}{\partial\Omega}$, not just on $\class{ntn-dOm}{\partial\Omega}$ itself. This is the class of $\psi$ used to define weak derivatives (@def:weak-derivative).</p>

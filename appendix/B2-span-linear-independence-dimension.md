title: Span, linear independence, dimension
status:
- defined
---
<p>The <em>span</em> of functions $\varphi_1,\dots,\varphi_N$ is the set of all linear combinations $\sum c_k\varphi_k$ with real $c_k$. They are <em>linearly independent</em> if $\sum c_k\varphi_k\equiv0$ only when every $c_k=0$. Independent functions spanning a space form a <em>basis</em>, and the number of basis elements is the <em>dimension</em>. It is a standard fact (cited) that every basis of a given space has the same size.</p>
